# APOC-DIGITAL

Sistema Integrado de Apoio à Operação Aeroportuária — Protótipo.

## Versão 2
Estrutura conceitual inspirada no material **APOC ON BOARD**, organizada em:
- Dashboard
- Consulta de aeronaves
- Consulta de posições
- Procedimentos rápidos
- Consulta rápida centralizada
- Visão da operação
- Referências e base de conhecimento

A V2 transforma temas apresentados no material de referência — aeronaves, posições, procedimentos, comunicação, operação e fontes de apoio — em módulos de uma aplicação web.

**Aviso:** este repositório contém apenas dados fictícios e demonstrativos. Não utilizar para decisões operacionais.
